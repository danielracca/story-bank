# Delivery Rubric

Six dimensions, 1-5 each. Score honestly. Report the line, then coach one thing.

---

## Clarity — did the point land early?

| | |
|---|---|
| 5 | First sentence states the claim. Listener knows the answer before any context. |
| 4 | Point arrives within two sentences. |
| 3 | Point arrives, but after setup. |
| 2 | Point implied, never stated. |
| 1 | Listener has to infer the answer from the events. |

Most common failure. The fix is mechanical: move the last sentence to the front.

## Structure — could someone follow the sequence?

| | |
|---|---|
| 5 | Clean frame. Each beat sets up the next. No backtracking. |
| 4 | Sound structure, one detour. |
| 3 | Followable but chronological rather than shaped. |
| 2 | Doubles back, adds context late, "oh and I should have said". |
| 1 | No discernible shape. |

Tell: repeated "sorry, going back a bit" — the story is being assembled live rather than retrieved.

## Specificity — was their own contribution visible?

| | |
|---|---|
| 5 | Exactly what they decided and did. Concrete details. "I" used accurately. |
| 4 | Contribution clear, some generic patches. |
| 3 | Mostly "we". Individual role inferable. |
| 2 | Entirely team-level. Could be anyone on that team. |
| 1 | Abstractions only — "aligned stakeholders", "drove clarity". |

Diagnostic question: could a listener describe one thing this person actually did? If not, score 2 or below.

## Outcome — did anything change?

| | |
|---|---|
| 5 | Specific result with a number or a clear before/after, plus the lesson. |
| 4 | Clear result, no number. |
| 3 | Result stated vaguely — "it went well". |
| 2 | Stops at "we shipped it". |
| 1 | Ends mid-story. |

Shipping is not an outcome. Ask what was different afterwards.

## Brevity — did they stop when done?

| | |
|---|---|
| 5 | Inside target length, ends deliberately. |
| 4 | Slightly long, still tight. |
| 3 | Runs about 50% over, some padding. |
| 2 | Double the target. Trails off. |
| 1 | Rambling; listener stopped tracking. |

Targets: quick question 30-60s · behavioural 60-120s · strategic 45-90s · rapport 30-45s.

Text estimate: 130-150 spoken words per minute.

## Delivery — how did it sound?

| | |
|---|---|
| 5 | Pauses instead of fillers. Short sentences. Strong open and close. |
| 4 | Occasional filler, mostly controlled. |
| 3 | Noticeable fillers or long compound sentences. |
| 2 | Frequent "um", "basically", "you know". Sentences run on. |
| 1 | Hard to follow through the verbal noise. |

Score from a transcript where possible — fillers survive transcription even when the speaker cannot hear them.

---

## Reading the total

- **26-30** — ready. Move to a harder round or a different story.
- **20-25** — solid. One targeted fix per rep.
- **14-19** — the structure is not automatic yet. Go back to the five anchors before practising delivery.
- **Below 14** — the story itself may be the problem, not the telling. Check it has a real tension and a real turn; if it does not, it may not be a story worth keeping.

## Coaching rules

- One fix per rep. People cannot change six things at once.
- Always show the better version of the weakest sentence. Naming a flaw without a replacement leaves them stuck.
- Praise the specific, not the general. "The detail about the screenshot is what makes it stick" beats "great story".
- If the same dimension scores low three times running, stop drilling and fix the underlying story entry in `story-bank.md`. Practice cannot fix a missing outcome.
